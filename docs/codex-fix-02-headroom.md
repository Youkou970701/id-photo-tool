# 头顶留白修复说明（2026-10-16，待 Claude 复验）

对应 `codex-handoff-02-headroom.md` 的「必修 1」及「观察」。未读取、使用或提交用户照片。

## 实现

1. 人脸检测 → MODNet 分割 → 叠加原图 alpha → 定位头顶 → 取景并检查越界/放大倍数 → 渲染并换底（保留前景 alpha）→ 输出终检 → 编码 → 校验尺寸/字节 → 排他保存。
2. `findHeadTop` 在脸中心 ±0.6 倍脸宽列带内，从上往下找第一行 alpha > 128。原图透明区域不被当作有效前景。
3. `MIN_HEADROOM_RATIO=0.08`、`MAX_HEADROOM_RATIO=0.14`，默认取中间值 11%。较高帽子/发型必要时扩大画幅，为下巴和肩部保留空间；最终画幅仍须通过原有 12% / 5% / 15% 越界检查及 1.5 倍放大限制，1.2～1.5 倍提醒继续保留。
4. `renderPortrait` 保留输出尺寸的前景 alpha；保存前先检查全幅前景最上点：小于 `MIN_OUTPUT_HEADROOM_RATIO=0.05` 时报「头顶离照片上沿太近」，不保存。再检查脸中心列带留白确实在 8%～14%，不是只相信理论裁剪坐标或 JPEG 底色。
5. 当 alpha 已贴近原图上沿（容差为脸高 2%，向上取整，避免 1～2px 抗锯齿绕过），无法从蒙版还原缺失的头顶。保留首轮的人脸框完整性判据专门拒绝截断额头；该估算不再用于头顶取景。原特写仍成功、原截断额头仍失败。
6. 所有成功提示增加「请确认未戴帽子、未戴深色眼镜」。不宣称可自动检测帽子。

## 回归测试

原有 35 条保留，增加 6 条，总计 41 条通过，完整输出见 `test-results-02.txt`：

- 合成 alpha：列带外高光忽略、alpha=128 不计为前景、空蒙版拒绝。
- NASA 公有领域人像合成约 0.6 倍脸高的帽子，使用真实 MODNet，输出前景留白落在 8%～14%。
- 同一公有领域人像向上拉伸头发，295×413、白底和蓝底都成功；除返回比例外，独立扫描实际输出 JPEG 验证发顶留白。
- 合成分割蒙版模拟带外贴顶残留，全流程必须被终检拒绝且不生成文件。
- 合成截断额头 alpha 从第 0 / 1 / 2 行开始时均须拒绝，不被软边缘绕过。
- 终检的 5% 安全线、头顶 8% / 14% 区间均验证包含边界；越界拒绝。
