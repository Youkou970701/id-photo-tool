## 必修 1：头顶位置是估算的，戴帽或发型高时会顶到上边

现状：`cropForFace` 用 `face.y - face.height * 0.35` 估算头顶，再留 9% 的空白。YuNet 的框只覆盖五官，帽子、盘发、蓬松发型的高度都不在估算范围内。
实测：站姿照输出里，帽顶离上沿只有 **6px / 413px = 1.5%**；同一个人的自拍是 15.3%。

要求：
- 已经有 MODNet 的 alpha，用它找真实头顶：在人脸中心 ±0.6×脸宽 的列带里，从上往下找第一行 alpha > 128 的位置，把它当作头顶
- 取景时让头顶到上沿的留白落在 **8%–14%**（写成常量）。要满足这个范围需要的上溢超过 `MAX_TOP_OVERFLOW_RATIO`，就按现有规则失败
- `renderPortrait` 之后再加一道终检：输出图里前景最高点到上沿的距离 < 5%，就失败，提示「头顶离照片上沿太近」，不产生文件
- 抠图要先于裁剪执行（现在顺序是 validateCrop → segment → crop，需要调整），注意别让 `validateCrop` 的放大倍数判断失效
- 回归测试：在公有领域人像头顶上合成一块高约 0.6×脸高 的深色「帽子」区域（或直接用 `astronaut.png` 向上拉伸头发区域），断言输出头顶留白在 8%–14%；原有特写、额头被切两条必须保持原结果
