# 撤掉自动扶正与头顶残片防护（待 Claude 真人复验）

对应 `codex-handoff-04-pose-rollback.md` 必修 1、必修 2。本轮只使用 NASA 公有领域 astronaut 派生图及合成蒙版/关键点，没有读取或使用用户照片。

## 改动

- 删除整图扶正、roll 检测/提示/拒绝、旋转后复检、局部关键点复测和 `validity.js`。`detectFaces` 恢复单次全图推理；与 `d6d3925` 相比只增加五个关键点解码。
- `validateCrop` 恢复 `d6d3925` 的矩形上/下/侧溢出公式及 12% / 5% / 15% 边界。输出不再返回 `roll`、`rotated`。
- yaw 仅提醒，常量 `WARN_YAW_RATIO=0.2`。达到阈值统一提示「脸部可能偏向一侧，请自行确认是否正面」，更大偏移也不拒绝；关键点缺失、非有限或眼距为零时返回 `yaw:null`，跳过提醒。
- 免冠提示补上「头部摆正」，不自动判断歪头。
- `findHeadTop` 从人脸框中心的 alpha > 128 像素做四连通搜索，仅在这一连通块中定位头顶。脸中心列带仍为 ±0.6 倍脸宽；全宽输出安全检查也使用同一人脸种子，避免无 face 时重新认到背景残片。种子无前景时明确失败，不随意挑别的前景。
- 整个连通块的最高点不能高于 `face.y − MAX_HEAD_ABOVE_FACE_RATIO × face.height`，常量为 1.2，恰好边界允许；超出报「人像抠图异常，请更换背景简单的照片」。
- 渲染返回完整映射人脸框，输出终检新增 `MIN_OUTPUT_FACE_HEIGHT_RATIO=0.30`，不足即失败，再检查同一连通块的全宽 5% 安全线和列带 8%–14% 留白。

## 验证与限制

保留 `d6d3925` 全部 41 项测试场景，删除自动扶正/有效性掩码相关测试，保留 YuNet 关键点解码测试。旧纯 alpha 单点测试补成与脸中心相连的形状；带外贴顶测试补连接，继续验证全宽安全线。原高帽夹具的悬空方帽在真实 MODNet 中几乎未被识别为前景，改为贴合头发的圆顶帽，仍保持 0.6 脸高、真实模型及原头顶/留白断言。所有测试仍使用公有领域派生图或合成数据。

`node scripts/test-all.mjs` 全部 50 项通过：原 41 项场景 + 保留的关键点解码 1 项 + 本轮 8 项。新增覆盖不连通残片、四邻域而非对角连通、1.2 脸高包含边界、0.29/0.30 输出占比、±10° 输入不旋转且仅检测一次、正负 yaw 0.19/0.2/0.6 的仅提醒策略，以及坏/缺关键点仍可生成。完整运行日志见 `test-results-04.txt`；脸部特写、HEIC、6200px 输入等原场景均通过。

连通分析用于头顶定位及终检，不额外删除实际蒙版中所有独立 alpha，以免未经验证地破坏离散发丝等细节。最终取景范围内的抠图残留仍需人工检查；不能据此宣称所有背景残片均已清除。用户站姿照和自拍恢复情况由 Claude 用真人照片复验，本轮没有拿用户照片自测。
